# مجلد الموديلات ثلاثية الأبعاد

ضع الموديلات بصيغة `GLB` داخل هذا المجلد بالأسماء التالية:

- `camel.glb` — موديل الجمل. يتم تحميله تلقائيًا بدل الموديل البرمجي الحالي.
- `oasis.glb` — موديل الواحة مستقبلًا.
- `camp.glb` — موديل المخيم مستقبلًا.
- `ruins.glb` — موديل الآثار مستقبلًا.
- `village.glb` — موديل القرية مستقبلًا.

## تجهيز موديل الجمل

- نقطة الأصل في منتصف الجمل عند مستوى القدمين.
- الاتجاه الأمامي نحو المحور `+Z`.
- يفضل ألا يتجاوز الملف 8 ميجابايت للويب.
- استخدم خامات مدمجة داخل ملف GLB.
- أسماء الحركات المقترحة: `Idle`, `Walk`, `Run`, `Sprint`, `Jump`.
- سمِّ مجسم السرج أو غطائه باسم يحتوي على `Saddle` أو `Blanket` حتى يعمل تغيير اللون عند فتح المكافأة.

إذا لم يوجد `camel.glb` أو تعذر تحميله، تستخدم اللعبة موديل الجمل البرمجي الحالي تلقائيًا.
